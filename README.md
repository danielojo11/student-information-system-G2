# Student Information Management System
SEN 401 Lab Test 1 - Collaborative Software Development Using Git and GitHub.
## Project Structure

- `index.html` — Student registration form and records table.
- `style.css` — Application layout, form styling, and table styling.
- `script.js` — JavaScript application logic.

## Student Registration Form

The form collects a student's name, matriculation number, and programme.

## Student Records Table

The records table is designed to display registered students with the following columns:

- Serial number
- Student name
- Matriculation number
- Programme

## Collaboration Workflow

1. Create a feature branch for each assigned task.
2. Make focused changes and commit them with meaningful messages.
3. Push the feature branch to GitHub.
4. Open a pull request targeting `main`.
5. Review changes and resolve any merge conflicts before merging.

## Testing

Verify the registration form, table layout, required fields, and application behaviour in a browser.
